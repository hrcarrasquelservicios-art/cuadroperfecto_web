# Artes de distribución

Los artes aprobados se publican aquí con un nombre inmutable: `YYYY-MM-DD/slug-version.ext`. Registre cada archivo en `manifest.json` con URL HTTPS final, tipo y reunión. GitHub Pages decide los encabezados de caché: el manifest no promete `Cache-Control`. La interfaz consume datos nativos; ningún arte es fuente de un pronóstico.
